# HomeScreen

A dashboard image server for the Google Nest Hub. It renders a 1024×600 PNG
on every HTTP request and casts it to a named Cast device on a 55-second loop,
so the clock and moon phase are always current.

## What it displays

| Module | Position | Size |
|--------|----------|------|
| Moon phase image | Right side, vertically centered | 80% of screen height |
| Clock (12-hour, e.g. `3:45`) | Left-justified, bottom | 20% of screen height, bold sans-serif |

The moon phase image is fetched from a local Home Assistant instance on every
render. The dashboard background is black.

## Files

| File | Purpose |
|------|---------|
| `dashboard.py` | Image composition — all `render_*` modules live here |
| `server.py` | HTTP server; re-renders on every `GET /dashboard.png` |
| `cast.py` | Casts the dashboard URL to a Cast device every 55 seconds |
| `setup.sh` | Raspberry Pi setup script (idempotent) |
| `requirements.txt` | Python dependencies |
| `homescreen.env` | Runtime config generated by `setup.sh` — not committed |

## Raspberry Pi setup

Clone the repository and run `setup.sh` once:

```bash
git clone <repo-url> ~/HomeScreen
cd ~/HomeScreen
bash setup.sh
```

The script will:

1. Create a Python virtual environment at `.venv/` and install dependencies
2. Scan the local network for Cast devices and list their names
3. Prompt for the Cast device name (saved to `homescreen.env` for future runs)
4. Write and enable two systemd services that start on every boot

Re-run after any `git pull` to apply updates — the device name is preserved:

```bash
git pull && bash setup.sh
```

### Useful commands

```bash
systemctl status homescreen           # image server state
systemctl status homescreen-cast      # cast controller state
journalctl -u homescreen -f           # image server logs
journalctl -u homescreen-cast -f      # cast controller logs
sudo systemctl stop homescreen-cast   # stop casting without stopping the server
```

## Services

### `homescreen` — image server

Runs `server.py` on port 2001. Responds to `GET /` and `GET /dashboard.png`
with a freshly rendered PNG. `Cache-Control: no-store` ensures the Cast device
always fetches a new frame.

### `homescreen-cast` — cast controller

Runs `cast.py` in a loop. Every 55 seconds it discovers the configured Cast
device by friendly name using zeroconf, calls `play_media` with the dashboard
URL, then sleeps. Failures are logged and retried; the service restarts
automatically if it crashes.

## Runtime configuration (`homescreen.env`)

Generated by `setup.sh`. Not committed to git.

| Variable | Description | Default |
|----------|-------------|---------|
| `CAST_DEVICE` | Friendly name of the Cast device | *(prompted)* |
| `DASHBOARD_URL` | URL cast to the device | `http://<pi-ip>:2001/dashboard.png` |
| `CAST_INTERVAL` | Seconds between casts | `55` |

`DASHBOARD_URL` is recomputed from the Pi's current IP each time `setup.sh`
runs, so it stays correct if the Pi's DHCP address changes.

## Image configuration (`dashboard.py`)

All layout constants are at the top of `dashboard.py`:

| Constant | Description | Default |
|----------|-------------|---------|
| `SCREEN_W` / `SCREEN_H` | Output image dimensions | `1024` / `600` |
| `BACKGROUND` | RGB background colour | `(0, 0, 0)` |
| `MOON_URL` | Moon phase image source | `http://homeassistant:1969/moon.png` |
| `MOON_HEIGHT_RATIO` | Moon diameter as fraction of screen height | `0.80` |
| `MOON_MARGIN_RIGHT` | Pixels between moon and right edge | `0` |
| `CLOCK_COLOR` | RGB clock colour | `(255, 255, 255)` |
| `CLOCK_FONT_RATIO` | Font size as fraction of screen height | `0.20` |
| `CLOCK_MARGIN_LEFT` | Pixels from left edge | `24` |
| `CLOCK_MARGIN_BOTTOM` | Pixels above bottom edge | `16` |
| `FONT_CANDIDATES` | Ordered list of bold sans-serif font paths to try | DejaVu → Liberation → Noto → FreeSans |

The server port is defined once in `server.py`:

```python
PORT = 2001
```

After changing any value, restart the affected service:

```bash
sudo systemctl restart homescreen        # after dashboard.py or server.py changes
sudo systemctl restart homescreen-cast   # after cast.py changes
# or restart both:
sudo systemctl restart homescreen homescreen-cast
```

## Adding a new display module

1. Write a `render_*(canvas: Image.Image) -> None` function in `dashboard.py`
2. Call it from `generate()` in the order layers should be composited
3. Add any new pip dependencies to `requirements.txt`
4. Run `bash setup.sh` to install deps and restart the service
